# Dream-RSI SDK 0.2.0a3 — Safer trees and cheaper policy search

This alpha update fixes two concrete gaps in the discovery-tree and policy
improvement loop. Dream-RSI SDK remains an independent, unofficial project by
**TheAstrayDev**, unaffiliated with Google or Google DeepMind.

## Recorded attempts stay recorded

`DiscoveryTree` now snapshots the root state and each attempt's state, proposal,
action, observation and metadata when the node is added. Previously, an adapter
could reuse a mutable observation and change a recorded node before `commit()`.
For example, the node's score could remain `1.0` while its observation changed
from `{"quality": 1.0}` to `{"quality": -1.0}`. Replay then saw contradictory
evidence. Node insertion now owns a copy of the attempt data.

## Free policy search explores different behaviors

`DeterministicPolicyOptimizer` now uses its existing candidate limit to replay
short one- and two-branch policies and a one-attempt-per-round balanced policy before
trying incumbent-specific parameter changes. This costs no LLM calls.

On a fixed two-branch regression tree, the previous optimizer's five generated
`BalancedPolicy` variants all attained raw quality `1.0` with **three attempted
expansions**. A one-branch, depth-one policy attains `1.0` with **one attempt**.
The new portfolio includes that candidate, and the default improvement loop
promotes it on the recorded training tree. This is a deterministic counterexample
to the old search coverage, not a result on new tasks. Use independent holdout
worlds and your own quality metric before adopting a policy in an application.

## Install

```bash
python -m pip install --upgrade dreamrsi==0.2.0a3
```

No migration is required for existing saved trees or policy bundles. The
default optimizer's candidate order has changed; start a new campaign for a
clean comparison with earlier releases. Custom optimizers are unaffected.

The source distribution now contains only package source and release
documentation. Local, untracked benchmark and marketing files are excluded.

Validation: 321 tests passed, two optional tests skipped; Ruff passed locally.
