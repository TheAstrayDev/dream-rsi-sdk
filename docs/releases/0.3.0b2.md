# Dream-RSI SDK 0.3.0b2 — Live Inspector

See how your search branches, what each attempt returned and how a policy used
recorded evidence. This Beta release adds an optional local Inspector and a
shorter setup path to the existing quality, replay and memory APIs.

Maintained independently by **TheAstrayDev**, unaffiliated with Google or Google
DeepMind. Python 3.11+, zero required runtime dependencies, Apache-2.0.

![Live Inspector with actual active branches in the deterministic local demonstration](https://raw.githubusercontent.com/TheAstrayDev/dream-rsi-sdk/v0.3.0b2/assets/inspector-live.png)

Screenshots show the SDK's local demonstration: actual adapter attempts, no LLM
requests. They are interface evidence, not a model benchmark.

## Install and open

```bash
python -m pip install --pre --upgrade dreamrsi==0.3.0b2
dreamrsi watch --demo
```

The browser opens automatically. No account, hosting, Node.js or CDN is needed.

For a runnable integration starter:

```bash
dreamrsi init
python dreamrsi_app.py
dreamrsi watch
```

Run these from the same project directory. Replace the generated agent and
evaluator with yours; `init` refuses to overwrite an existing file.

## Connect an existing application

```python
from dreamrsi import DreamRSI, LiveInspector

with LiveInspector() as inspector:
    sdk = DreamRSI(
        agent=my_agent,
        evaluator=my_evaluator,
        policy=my_policy,
        budget=my_budget,
        inspector=inspector,
    )
    result = await sdk.run(task)
    print(result.report())
```

Use your application's integrations inside an async function. In another
terminal, run `dreamrsi watch` from that directory to observe execution live.
The inspector does not replace persistent policy memory or imported bundles.

## Explore and compare

- Animate actual in-flight branches; distinguish completed, failed and
  awaiting-batch attempts.
- Select a node to read its recorded answer, evaluation, diagnostics and
  optional policy reason. The viewer does not infer private model reasoning.
- Pan, zoom, collapse branches, follow active work and play recorded history
  without repeating model calls. Keyboard and reduced-motion support are included.
- Compare recorded policy replay and overlay the revealed path. Missing
  continuations remain unknown; quality contracts retain the effective policy.
  Comparisons never promote policies.
- Read quality, settled/reserved calls and declared historical preparation
  separately. Incomplete token and dollar usage stays unknown.

![Offline policy comparison on the same recorded world](https://raw.githubusercontent.com/TheAstrayDev/dream-rsi-sdk/v0.3.0b2/assets/inspector-policies.png)

The default `StrictReplay` makes no agent/evaluator calls. Custom replay engines,
policy code and callbacks retain their own behavior. Finite replay comparisons
do not prove generalization or all-in ROI.

## Reports and setup checks

```bash
dreamrsi doctor
dreamrsi inspect path/to/shared-policy.dreamrsi.json
dreamrsi watch --export dreamrsi-report.html
```

Export produces one self-contained HTML report; `result.report()` produces a
concise console summary. An HTML report is separate from the portable policy/tree
bundle made by `dreamrsi save`.

The observer uses a bounded background SQLite writer and the viewer is read-only,
bound to `127.0.0.1`. Captured content can contain private data: use
`LiveInspector(include_content=False)` where appropriate and review shared reports.
Common credential redaction is not a guarantee that arbitrary text is safe.

Existing search decisions, quality contracts and budget rules remain unchanged.
Instrumentation adds CPU/disk overhead and can affect very tight wall-clock limits.
This release makes no new real-model quality or cost claim.
