# Dream-RSI SDK 0.2.0a1

This alpha expands the SDK from one-off policy development toward reusable
policy campaigns. `AdaptivePolicyMemory` can load a saved champion for a related
task, check its raw quality, and run offline improvement only when configured
to do so. Replay now counts attempted expansions at the edge of a recorded
tree conservatively, and source-development feedback identifies revisions
that repeat the same decisions or only appear cheap because a continuation
was never recorded.

**Why 0.2.0a1?** The new policy-memory API and replay-accounting changes
broaden the experimental interface and can change which candidate is accepted.
That warrants a new minor alpha line instead of presenting this as a routine
patch. It does **not** signal production stability, parity with Google's
research system, or a proven end-to-end LLM-agent cost reduction.

The documentation now distinguishes two measured experiments:

- [Ternary Bonsai-27B Q2](../experiments/ternary-bonsai-diverse-2026-09-24.md)
  wrote a policy for a deterministic discovery-agent fixture. Across 64 fresh
  fixture tasks, counted operations were 248 for the learned-policy path
  including preparation versus 256 for the fixed baseline, with raw quality
  0.9 on every task. These operations are **not** model-agent calls or dollars.
- [GPT-6 Luna xhigh Fast](../experiments/luna-xhigh-discovery-v1.md) acted as
  both the task solver and policy developer. The accepted policies used two
  model responses per category instead of eight on the six held-out tasks.
  Preparation cost 94 requests, so the complete path was **100 versus 24**
  baseline requests; mean reported score was 72.293% versus 72.607%.

Only these two experiment records and their plots accompany this release.
Neither result proves broad generalization. Token and dollar costs that were
not measured remain unknown.

Install with `python -m pip install dreamrsi==0.2.0a1` after the PyPI
publication completes. Python 3.11 or newer is required. The package remains
independent and unofficial, authored solely by TheAstrayDev.
