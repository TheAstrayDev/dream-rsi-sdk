# Manual launch tracker

No SDK telemetry is required. All cells below are intentionally blank. Record only public
aggregate data and voluntary feedback. Do not create a dossier of strangers' activity.

## Definitions

- **Qualified conversation:** someone describes a real task with generated candidates and evaluation.
- **First run:** a voluntary report of a completed SDK example, not a download.
- **Integration attempt:** someone tries their own adapter/task, even if it fails.
- **Own-task success:** that integration executes with a defined evaluator; it need not beat baseline.
- **Repeat user:** the same consenting tester reports another experiment on a later occasion.
- **Outcome:** improved, equal, worse, failed, or unknown; keep the baseline and budget alongside it.

If someone finds the project on DEV and later on X, count one person, not two activated users.
Ask “Where did you first find it?” optionally; do not force attribution. GitHub traffic is
aggregate and PyPI downloads include automation. UTM parameters on a GitHub link do not
magically provide a campaign analytics dashboard; this plan relies on voluntary source reports.
