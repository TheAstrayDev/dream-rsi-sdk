## How to interpret failed checks

Some guessed documentation/submission endpoints could not be retrieved. They are not included
as authoritative posting routes. Use the verified homepage and visible navigation where the
exact editor or form is account-dependent. No private groups, Discord channels, editor names,
subscriber reach estimates or fees have been invented.
