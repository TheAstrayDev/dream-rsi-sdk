# Участие в Dream-RSI SDK

Спасибо за интерес к независимой реализации. Приоритет проекта — простые интеграции,
корректный replay и измеримые результаты. Это не официальный репозиторий Google.

## Предложить изменение

Для ошибки приложите версию Python и SDK, минимальный пример без приватных данных,
ожидаемый результат и фактическое поведение. Для изменения API опишите задачу интегратора
и покажите, насколько проще становится вызывающий код.

Перед большой реализацией заведите issue, чтобы согласовать её с [Roadmap](README.md#roadmap).
Исправление воспроизводимой ошибки можно сразу предложить небольшим pull request.

## Локальная проверка

```bash
python -m venv .venv
# Активируйте окружение для своей ОС.
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ruff check src tests
python -m pyright
```

Тесты должны работать без секретов, платных API и подключённой модели.
Добавляйте регрессионный тест для изменения поведения. Для новых адаптеров приведите
пример и объясните состояние, параллелизм, отмену и стоимость операций.

## Инварианты

- Не показывать политике ещё не раскрытые результаты replay.
- Не смешивать обучающие и проверочные оценки.
- Не создавать успешные оценки из исключений или отсутствующих данных.
- Не считать вызовы SDK достоверной денежной стоимостью провайдера.
- Не связывать ядро с обязательной зависимостью от конкретного фреймворка.
- Не обещать результатов исследования без воспроизводимого эксперимента.

Опишите в PR, что меняется для пользователя, почему и как это проверено.
